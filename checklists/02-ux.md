# 4.2 UX 사용성

적용: UI앱 ● / CLI ○ (메시지·도움말) / API·배치 –
판정 주의: 주관적 항목은 `Suspected` 또는 `RequiresManualReview`로 표기하고 AI 의견임을 명시.

| ID | 확인 방법 | 문제 기준 | 기본 심각도 |
|---|---|---|---|
| UX-01 | 핵심 작업 3~5개를 정해 클릭/입력 단계 수 센다 | 불필요한 단계, 같은 정보 재입력 | P3 |
| UX-02 | 내비게이션 구조·메뉴 깊이 | 핵심 기능이 3단계 이상 깊음 | P3 |
| UX-03 | 용어 일관성·직관성 (같은 개념 다른 이름) | 화면마다 용어 다름, 내부 용어 노출 | P3 |
| UX-04 | 위험 동작(삭제·발송·결제) 확인/실행취소 | 되돌릴 수 없는데 경고 없음 | P1 |
| UX-05 | 제출/저장/삭제 후 피드백(토스트·상태) | 성공/실패를 알 수 없음 | P2 |
| UX-06 | 빈 목록·첫 사용 안내 | 빈 화면에 설명·다음 행동 없음 | P3 |
| UX-07 | 오류 문구: 원인+해결 행동 포함 여부 | "오류가 발생했습니다"만 표시 | P3 |
| UX-08 | 입력 중 이탈·실패 시 입력값 보존 | 에러 후 폼이 비워짐 | P2 |
| UX-09 | 반복 작업(일괄 선택·단축키·기본값) | 같은 작업을 수십 번 수동 반복 | P3 |
| UX-10 | 기능 발견성: 핵심 기능이 보이는 위치에 있는가 | 숨은 기능, 아이콘만 있고 설명 없음 | P4 |
