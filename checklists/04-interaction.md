# 4.4 인터랙션 품질

적용: UI앱 ● / 나머지 –

| ID | 확인 방법 | 문제 기준 | 기본 심각도 |
|---|---|---|---|
| I-01 | 버튼·링크 스타일의 hover/focus/active/disabled 정의 | 상태 스타일 없음, focus 제거(`outline:none`)만 있음 | P2 |
| I-02 | 비동기 버튼: 진행 중 비활성+스피너 | 진행 표시 없음, 연타 가능 | P2 |
| I-03 | 제출 중복 방지 (disabled/디바운스/멱등키) | 연타 시 중복 요청 | P2 |
| I-04 | 모달: ESC 닫기, 포커스 트랩, 배경 스크롤 잠금, 닫을 때 포커스 복귀 | 키보드로 닫기·이동 불가 | P2 |
| I-05 | 드롭다운/툴팁/토스트: 외부 클릭·ESC·자동 닫힘 | 안 닫힘, 겹침 | P3 |
| I-06 | Enter/Tab 동작: 폼 제출, 탭 순서 | 탭 순서 뒤섞임, Enter 무반응 | P2 |
| I-07 | 전환/애니메이션 길이·`prefers-reduced-motion` 대응 | 과한 모션, 감소 모션 무시 | P3 |
| I-08 | 모달 열린 상태에서 뒤 화면 키 입력 가로채임 여부 | 단축키가 뒤 화면 동작시킴 | P3 |
