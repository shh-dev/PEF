# 4.6 반응형 및 호환성

적용: UI앱 ● (모바일 우선 앱이면 최우선)
실화면 확인 폭 기준: 360 / 390 / 768 / 1024 / 1440. 승인된 환경에서 스크린샷으로.

| ID | 확인 방법 | 문제 기준 | 기본 심각도 |
|---|---|---|---|
| R-01 | viewport meta, 미디어쿼리/컨테이너쿼리 존재 | viewport 없음, 고정 폭 레이아웃 | P2 |
| R-02 | 각 폭에서 가로 스크롤 발생 여부 | 360px에서 가로 스크롤 | P2 |
| R-03 | 긴 텍스트·긴 이름·URL 줄바꿈/말줄임 | 레이아웃 깨짐, 넘침 | P3 |
| R-04 | 데이터 많을 때(수백 행) 레이아웃·페이징 | 화면 밖으로 밀림, 무한 길이 | P3 |
| R-05 | 모달/드롭다운이 작은 화면에서 잘림 | 닫기 버튼이 화면 밖 | P2 |
| R-06 | 터치 타깃 최소 44px (→ 4.7) | 작은 타깃·붙은 버튼 | P3 |
| R-07 | 브라우저 확대 200%, 글꼴 크기 변경 | 내용 잘림·겹침 | P3 |
| R-08 | 지원 브라우저 명시, 비표준 API 사용 시 폴백 | 최신 API 무폴백 | P3 |
| R-09 | iOS 입력 확대(폼 폰트 16px 미만), 안전영역 | 포커스 시 화면 확대/가림 | P3 |
| TC-01 | 휴대폰 크기(아이폰·갤럭시)로 모든 화면을 열고 손가락으로 밀어 끝까지 내려가는지 (`pef touch`) | 밀어도 중간에 멈춤, 스크롤 잠김 | P2 |
| TC-02 | 버튼·링크가 화면 밖으로 잘리거나 옆으로 밀려 나가지 않는지 (`pef touch`) | 눌러야 할 버튼이 화면 밖 | P2 |
| TC-03 | 키보드가 올라와도(기기별 높이 가정) 입력칸과 저장 버튼이 보이는지 (`pef touch`) | 입력칸·고정 버튼이 키보드에 가림 | P2 |
| DK-09 | (데스크톱) 고DPI·다중 모니터·창 크기/위치 복원·최소 크기 | 배율에서 레이아웃 깨짐 | P3 |
| MB-05 | (모바일) 다양한 화면 크기·노치·시스템 글자 크기 확대 | 글자 잘림, 버튼 가려짐 | P2 |
