# 4.17 운영 및 관측성

적용: API ● / 배치 ● / UI앱 ○ / 라이브러리 –

| ID | 확인 방법 | 문제 기준 | 기본 심각도 |
|---|---|---|---|
| O-01 | 로그 형식(구조화, 레벨, 요청 ID), 에러 로그에 원인 포함 | 에러가 삼켜지거나 맥락 없음 | P3 |
| O-02 | 민감정보 로그 금지(→ 4.13/4.14) | 토큰·개인정보 로그 | P1 |
| O-03 | 오류 추적 수단(Sentry 등) 또는 대체 | 장애를 사용자 제보로만 인지 | P3 |
| O-04 | 헬스체크 엔드포인트·상태 확인 수단 | 살아있는지 알 방법 없음 | P3 |
| O-05 | 주요 지표(응답시간·오류율·큐 길이) 수집 | 지표 없음 | P3 |
| O-06 | 알림: 장애·자동 정지·실패 누적 알림 | 조용히 실패 방치 | P2 |
| O-07 | 로그 보존·회전(디스크 가득 방지) | 무한 증가 | P2 |
| O-08 | 시각 표기 일관성(KST 또는 UTC 명시) | 시간대 혼재로 장애 분석 곤란 | P3 |
