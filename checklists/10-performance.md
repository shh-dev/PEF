# 4.10 성능 및 경량화

적용: UI앱 ● / API ● / CLI ● / 배치 ○
원칙: **측정 없이 개선 주장 금지.** 개선 전후 측정값을 같은 환경에서 기록(환경·시각 KST 포함). 코드 줄 수 감소 ≠ 성능 향상.

| P-02 | 라우트/무거운 컴포넌트 코드 분할·지연 로드 | 전부 초기 번들에 포함 | P3 |
| P-03 | 이미지: 포맷·크기·lazy·width/height 지정 | 원본 대용량 이미지 직접 사용 | P2 |
| P-04 | 폰트: 서브셋·display swap·사용 weight 수 | 전체 폰트 다수 weight 로딩 | P3 |
| P-05 | 불필요한 리렌더/루프 내 무거운 연산 (코드 리뷰) | 입력마다 전체 재계산 | P3 |
