# UI/UX 근거 자료 (참고용 — 점검 항목 아님)

UI 영역(4.2 UX, 4.3 시각, 4.4 인터랙션, 4.5 상태, 4.6 반응형, 4.7 접근성, 4.20 일관성)에서 Finding을 낼 때 "무엇을 보고 그렇게 판단했는가"의 근거를 찾는 곳이다. 이 목록은 점검 항목이 아니다. 사이트를 열지 못하면 건너뛰고 해당 판단은 근거 없이 단정하지 않는다(NotTested 또는 Suspected).

## 사용 원칙

- 최신 디자인이라는 이유만으로 채택하지 않는다. 실제 운영 서비스에서 쓰이는 UI를 먼저 본다.
- 여러 서비스에서 반복되는 공통 패턴을 확인한다. 한 곳에서 본 것은 패턴이 아니라 사례다.
- 시각적 완성도와 사용성을 구분해 평가한다.
- 기존 디자인 시스템·컴포넌트 재사용을 우선한다.
- 스크린샷을 복제하지 않고 설계 원칙만 추출한다.
- 실제 사용 기간이나 성과가 확인되지 않으면 "검증된 패턴"이라고 단정하지 않는다.
- 로그인·유료 사이트가 열리지 않으면 사용자에게 요청하지 말고 건너뛴다. 근거를 못 얻은 것을 보고서에 적는다.

## 쓰는 법 (Finding 근거 쓰기)

- 근거로 쓸 때는 `evidence`에 "어느 사이트의 어떤 항목/글을 봤고, 거기서 뽑은 원칙이 무엇인지"를 한 줄로 쓴다. 이미지 복제나 길게 옮겨 적기는 하지 않는다.
- 앱 유형이 업무도구·대시보드면 1~2순위, 폼 많은 앱이면 Baymard, 컴포넌트가 제각각이면 Component Gallery를 먼저 본다.
- 참고 자료는 판단을 돕는 것이지 점수를 올리는 근거가 아니다. 점수는 `docs/SCORING.md`의 감점표만 따른다.
